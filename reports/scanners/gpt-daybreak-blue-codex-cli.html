Methodology note
Full coverage; subscription-metered. gpt-daybreak-blue-latest is an OpenAI Codex CLI alias that, per OpenAI's own model docs, currently resolves to the same underlying weights as gpt-5.6-sol — the difference is the Daybreak program's defensive-cybersecurity system instructions and safety calibration, not a different model. Despite that, at matched high reasoning effort it scores well above plain Sol on both languages (Python F3 80.0 vs 77.8, TS/JS F3 79.2 vs 72.1, Overall 79.5 vs 74.7) and on a same-repo pilot the gap was starker still (F3 88.3 vs 57.1). Whatever the Daybreak instructions change, it changes scanning behavior substantially. OpenAI's official Daybreak pricing card lists this alias at the identical rate as gpt-5.6-sol ($4.00/$20.00 per 1M input/output, short context), with cached-input and long-context rates applied where recorded. The cost figure uses Codex's reported token usage, not billed spend, following the same convention as Sol. All 74 TypeScript / JS repositories were scanned on 2026-09-04 with the TS/JS prompt (hash sha256:45a1200d61e6); all 66 Python repositories were scanned on 2026-09-05 with the standard prompt. All 140 runs validated first time. The 63 Java runs use the same rate-based convention; their saved Codex usage metrics were restored from the original ctx272k campaign after matching every finding path and line to the normalized dashboard copy.
